1. context 審計：agent 對話 log → 各來源 token 占比、重複工具輸出、建議 masking／摘要入口。
2. 前提檢查清單：prompt 草稿 → 缺漏的場景、格式、限制、歧義詞。
3. 範例相關度檢查：few-shot 範例＋任務描述 → 領域落差與數量警示（>8）。
4. judge 校準：人評與 LLM 評分 CSV → 相關係數、長度偏誤、各偏誤提示；先取約 10% 對照。
5. 評分穩健性：同題多 prompt 或擾動結果 → 分數變異、平均與最差情況。
6. 遺忘回歸：微調前後各能力分數表 → 掉幅與是否需 replay；含 safety 項目。
7. 反思四象限：修正前後對錯記錄 → 錯→對、對→錯比例，並對照 majority vote。
8. 推理長度分析：同題多次取樣的長度與對錯 → 分組正確率。
