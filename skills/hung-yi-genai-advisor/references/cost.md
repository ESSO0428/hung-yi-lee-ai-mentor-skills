# 成本太高

主要是 2023 年的 FrugalGPT 兩講；價格與 API 功能早已改變，只取結構，不取數字。

1. 成本拆輸入、輸出、固定項；單次便宜不代表便宜，看量。(vxxP S0002 · 2023)
2. 省法：縮短 few-shot 範例；多題併成一次呼叫（範例只送一次；準確率是否下降課堂未講）；快取相似答案。(vxxP S0003–S0005 · 2023)
3. Cascade：由便宜到貴，驗證模組分數過閾值就停。閾值要在目標資料上校準；強模型也會答錯弱模型答對的題。(vxxP S0007 · 2023；VpKN · 2023)
4. 推理模型的成本看思考長度，縮短方法見 reasoning-selfcorrect.md 第 8 點。(ip3X · 2025)
