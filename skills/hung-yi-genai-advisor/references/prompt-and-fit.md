# prompt 與「微調或 prompt」

來源格式見 sources.md。2023 與 2024–2025 的講法不同，使用時說明年代。

1. **先查前提有沒有給。** 症狀：答非所問、答成另一種合理解讀。補場景、地點、格式、字數；「載具」要寫成「超商結帳時店員問」。(lVda S0010 · 2025；A3Yx S0013 · 2024)
2. **說不清的需求給範例。** 範例貼近目標領域；約 4–8 個後邊際效益小。小模型能容忍錯標，大模型會被錯範例帶偏。(lVda S0013 · 2025；aZ_j · 2023 曲線)
3. **答案需要模型不知道的知識：把資料給它**，不要要它憑記憶。(A3Yx S0014 · 2024)
4. **專才或通才。** 單一明確任務且只在乎它的最佳表現，專才（微調）較有機會贏；要多功能、快速迭代，用通才加 prompt。證據只是翻譯一例、50 句，樣本小。(F58v S0005–S0009 · 2023)
5. **年代差異。** 2023 年偏「微調 vs prompt 二選一」；2024–2025 的課幾乎只教 prompt／context，只在「後訓練」講次談微調並強調風險（見 finetune-forgetting.md）。課程沒有給決策樹；任何決策準則都標為推論。
6. **不要先找神奇咒語。** GPT-3.5 數學題 2023/6 無咒語 72%→有 88%，2024/2 85%→89%，差距縮小。咒語當假說實測，不當定律。(lVda S0008 · 2025；A3Yx S0005 · 2024)
7. **直說「做什麼」，不說「不要做什麼」。**(A3Yx S0006 · 2024；M2Yg S0028 · 2025)
8. 封閉 API 只能改 x；開權重才有 f（訓練）選項，這是總開關的判斷依據。(lVda S0002 · 2025；M2Yg S0009 · 2025)

推論（非講者原話）：x 改了數輪仍無起色、且有足量標註資料與開權重時，才值得評估微調；評估前先讀 finetune-forgetting.md。
