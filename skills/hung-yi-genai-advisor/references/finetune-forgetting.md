# 微調後舊能力變差（遺忘）

證據集中於 1B–7B 語言／語音模型；套到更大的 LLM 屬推論。

1. 症狀：新任務好了，舊能力或安全對齊掉了（「手術成功，病人卻死了」）。先回測舊能力，再宣稱微調成功。(Z6b5 S0051 · 2025)
2. 後訓練三面向都要評：Reliability、Generality、Locality。什麼問題都回同一答案是沒有 Locality。(EnWz S0008–S0017 · 2025)
3. Safety alignment 最脆弱，資料乾淨也救不了。(Z6b5 S0009–S0012 · 2025；EnWz S0020 · 2025)
4. 目標任務學得越好，遺忘越多。LoRA 少遺忘是因為少學；dropout、weight decay 擋不住。(Z6b5 S0019–S0029 · 2025；EnWz S0031 · 2025)
5. 首選 experience replay：混入少量舊資料（實驗為 5%，非通則）。(Z6b5 S0030 · 2025；EnWz S0038 · 2025)
6. 沒有舊資料：讓模型自問自答生成；用 foundation model 自己的答案或改寫當目標。(Z6b5 S0037–S0042 · 2025；EnWz S0039 · 2025)
7. 教新知識的取捨：SFT 只能教模型已會的，教新知識反而傷害，RL 較安全。對齊資料重質不重量。(Ozos S0042–S0046 · 2025；Ozos S0006 · 2025)
8. 改單一知識用 model editing（ROME）；沒資料不能訓練用 task vector 加減；「忘掉」某能力用相減。(EnWz S0043–S0058 · 2025)
9. 年代差異：2023 講 finetune 只談專才路線、完全不談遺忘；2025 才有遺忘專講。(F58v · 2023 → Z6b5 · 2025)
