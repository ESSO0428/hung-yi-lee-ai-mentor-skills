# 課程沒講的部分

答到下列主題時，先寫「這部分課程沒有涵蓋」，再以「一般 ML／工程知識（非課程內容）」標示回答。

- prompt caching、structured output、MCP、各家 API 計價與參數（thinking budget 等）。
- 完整成本模型與延遲／吞吐。
- 位置偏誤與 judge 偏誤的現代緩解配方；評測集大小、信賴區間、顯著性檢定。
- RAG 切塊、embedding、重排等實作細節與 RAG 評估。
- 具體防禦 prompt injection 的方案（講者稱研究問題）。
- fine-tune 與 prompt／RAG 的決策準則：只有 2023 的專才通才一般原則。
- 遺忘證據集中於 1B–7B 語言／語音模型，非 LLM 結論皆屬推論。
- agent 失敗率的量化、多步驟幻覺累積；多為單次展示。
- 多數實驗是講者轉述論文，並非重現；ASR 稿有誤聽，引用數字前須回查影片。
