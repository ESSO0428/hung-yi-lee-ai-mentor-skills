# 評估 LLM 輸出

1. 先決定要考什麼能力，再選或蓋 benchmark；分清「要量的」與「量到的」。(dWQV S0045 · 2025)
2. 選擇題：先定義怎樣算答對；限制只輸出選項測的是遵循指令；做位置與符號穩健性檢查。(Hk8Z S0003–S0006 · 2024)
3. 字串重疊指標（EM、BLEU、ROUGE）會誤判，如「三」對「3」，至少加語意層。(dWQV S0009 · 2025；64hQ · 2025)
4. 沒有標準答案：人評可靠但有雜訊、不是黃金標準；人類偏好排行榜偏好「怎麼說」勝過「說了什麼」，要風格校正。(dWQV S0020–S0023 · 2025；s266 · 2025)
5. LLM-as-judge：先拿約 10% 資料對人類校準；叫它先解釋再給分；分數是機率分佈，別只取一次。(64hQ R8–R12 · 2025；A3Yx S0004 · 2024)
6. 偏誤清單：長度偏誤、自我偏好、「改過」就加分（7→8）、被假權威影響。(Hk8Z S0011 · 2024；dWQV S0038 · 2025)
7. 年代差異：judge 偏誤的量化多是 GPT-3.5／GPT-4o 時代，且未給緩解配方；位置偏誤兩年的課都沒系統講。
8. 污染：公開 benchmark 預設可能被高估；擾動題目重測，並用人類對照才可說背題。跨語言版本使刪題做不乾淨。(dWQV S0062 · 2025；s266 · 2025；Hk8Z S0028 · 2024)
9. Goodhart：指標變目標就失真；沒有「棄權」選項的評分獎勵亂猜，評分要讓「我不知道」比亂猜划算。(dWQV S0012–S0019 · 2025；64hQ · 2025)
10. 平均不一定對：同時報最差情況。例：語音合成 1% 暴走得 0 分。(dWQV S0042 · 2025)
11. prompt 改寫會改分數，比較模型時 prompt 要受控或多 prompt 取平均。(Hk8Z S0020 · 2024；dWQV S0061 · 2025)
12. 一併評延遲、價格、思考成本；推理模型看成本與推論長度。(dWQV S0041 · 2025；s266 · 2025)
13. 模型信心可信嗎：畫 calibration 圖。GPT-4 技術報告顯示 RLHF 後偏離對角線，僅此一例。(ksli S0008–S0009 · 2023)
14. 偏見：只置換一個屬性（性別、族群）比較；重複取樣看分布。(MSnv S0006–S0010 · 2024)
15. 幻覺與事實查核：推薦文獻逐筆外查；查核流程為抽陳述→轉問題→搜尋→比對，每步都可能錯。逐句皆對仍可能整體混淆同名實體。(MSnv S0001–S0006 · 2024)
16. 安全：區分 jailbreak 與 prompt injection；agent 讀進的外部內容不可信。防禦寫法課程只展示攻擊與衡量，細節在作業。(dWQV S0066–S0083 · 2025；64hQ R21–R25 · 2025)
