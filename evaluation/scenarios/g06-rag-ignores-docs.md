# G06 RAG 答案不採用檢索文件

- 覆蓋度：部分涵蓋（RAG 概念與失敗；切塊、embedding、重排、RAG 評估未涵蓋）
- 主題：檢索文件在 context 裡，模型仍用自己的記憶

## 使用者訊息

公司內部規章問答 RAG（向量檢索取 top-5 段落放進 prompt）。抽查 100 題：

```
檢索到含正確答案段落的題數      82/100
其中模型答案與段落一致          51/82
其中模型答案與段落衝突          19/82（回答成網路上通用的舊規則）
其餘為模糊或沒回答              12/82
```

有人說要換更好的 embedding；有人說直接微調。你怎麼看？

## 預期判斷

不是先換 embedding：82% 檢索已含答案，主要問題在模型不採用文件。要先對比「不給文件」與「給文件」的輸出，確認是否受文件影響；課程提到的 CAD 思路需要 logits，封閉 API 可能不行（推論）。RAG 只補資料不保證答對；要檢查檢索品質，同名實體會混成一人；有 reference 不等於引用真的支持那句話。模型對外部資訊的採信取決於其信念，離信念太遠會不被採信。微調不是第一步。

## 關鍵檢查

- 區分檢索失敗與使用失敗，並用使用者的數字。
- 提出「不給文件 vs 給文件」的對比實驗。
- 不把 embedding/切塊/重排說成他的內容。
- 引用逐條核對。

## GOOD 答案必含

1. 模型沒有資料庫，只會接龍；先搜尋再把結果與問題一起餵。(lwe3_x50_uw S0019)
2. RAG 只補資料，不保證答對；要檢查檢索品質，同名實體會混成一人。(lVdajtNpaGI S0024; M2Yg1kwPpts S0049)
3. 模型不理檢索文件：對比「不給文件」與「給文件」的輸出（CAD 思路），需要 logits，封閉 API 可能不行（標推論）。(m3i2mk5hs8U S0016)
4. 模型對外部資訊的採信取決於信念：離模型信念太遠或信心高時較不被採信；也偏好 AI 寫的文章。(M2Yg1kwPpts S0042-S0049)
5. 把資料給它，不要要它憑記憶；prompt 要明確。(A3Yx35KrSN0 S0014)
6. 有 reference 不等於引用真的支持那句話，逐條點開核對；事實查核流程每步都可能錯。(ZID220t_MpI; MSnvknLywUc S0001-S0006)
7. 想要的限制放程式硬擋，不放 prompt（例：要求引用原文、不一致時重試；屬套用，標推論）。(R6fZR_9kmIw S0020)
8. 先把 19/82 衝突題逐題看原因（檢索內容、prompt、模型信念）再決定改哪裡，不先微調（標推論）。
9. 一般 ML（標示）：embedding 選型、切塊、重排、混合檢索、RAG 專用評估指標；課程沒講。

## 不可

- 先建議換 embedding 或微調。
- 把切塊/重排/RAG 評估指標歸給他。
- 說「給了文件模型就會照做」。
- 說有檢索就沒有幻覺。
