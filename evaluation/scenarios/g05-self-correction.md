# G05 自我修正（請再檢查一下）

- 覆蓋度：已涵蓋（2024 與 2026）；具體 reward 與 RL 設計未涵蓋
- 主題：加一輪「請再檢查」

## 使用者訊息

我在數學應用題（500 題）上，想加一個步驟：模型先答，再用「請再檢查你的答案」讓它修正。結果：

```
第一次答案 acc  72.0%
修正後 acc      70.6%
錯->對 21 題；對->錯 28 題
```

我想改成「你上次答錯了，請重新思考」或換更嚴厲的語氣。可行嗎？還是這個方向就不對？

## 預期判斷

數據顯示：對->錯 (28) 多於 錯->對 (21)，「請再檢查」不穩定。語氣是會改變模型固執或動搖的變數，要實測並記錄四象限，不是假設有效。新的 reflection workflow 都要對照 majority vote（以算力為橫軸）；多 sample 再投票常勝過反思。模型缺的是知識還是修正行為是兩件事。

## 關鍵檢查

- 沒有直接幫使用者調語氣而不先對照 majority vote。
- 使用四象限（錯->對、對->錯）。
- 區分「知識」與「修正行為」。
- 不給「保證有效的咒語」。

## GOOD 答案必含

1. 「請再檢查一下」不穩定：弱模型可能把對的改錯，或只道歉。(lwe3_x50_uw S0006; m3i2mk5hs8U S0032)
2. 每個 reflection workflow 都要對照 majority vote，橫軸為算力；多 sample 再投票常勝過反思。(m3i2mk5hs8U S0039-S0042)
3. 語氣會讓模型固執或動搖，是要實測的變數；記錄錯->對、對->錯四象限。(m3i2mk5hs8U S0034-S0038)
4. 缺知識或缺修正行為是兩件事；真要教，走整條 pipeline 的 RL。(m3i2mk5hs8U S0043-S0047)
5. 2023 的做法：CoT、Self-Consistency 取樣投票；2024 把 CoT 重新解讀為拆解、每步多取樣、自查、錯就回退。(HnzDaEiN_eg; lwe3_x50_uw S0004-S0018)
6. 多模型討論優於單模型自省，有收益遞減；風險是討論太快結束。(inebiWdQW-4)
7. 若看到「推理越長越差」的圖，先查有無控制難度。(ip3XnTpcxoA S0002)
8. 一般 ML（標示）：500 題的統計不確定性、取樣 temperature 與 k 的選法；課程沒講。

## 不可

- 說嚴厲語氣會提高修正率。
- 不做 majority vote 對照就推薦 reflection。
- 把實驗數字說成通則。
- 把 pipeline 級 RL 說成他給的 recipe。
