# S07 微調後忘記舊能力（傳統模型）

- 覆蓋度：部分涵蓋（保守微調、層搬移已涵蓋；遺忘專講集中在 LLM，傳統模型多為推論）
- 主題：語音/影像模型微調後舊任務掉分

## 使用者訊息

我把一個預訓練的語音辨識模型（在英文與多種口音上都不錯）拿來微調成我們公司客服錄音（約 30 小時），全模型微調 20 epoch，lr=1e-4。

```
                     新任務 WER   原本英文基準 WER
微調前               24.8         6.1
微調後（20 epoch）   9.7          18.4
```

新任務很好，但原本通用能力壞了。這是 bug 嗎？怎麼辦？

## 預期判斷

不是 bug，是微調的典型現象：只優化新任務的 loss，看不到舊能力是否遺失。要先回測舊能力（已做）。若新舊都要，是 multitask / 持續學習問題。處方方向：少 epoch + 小 lr 的保守微調、conservative training（限制新舊輸出/參數距離）、只訓練部分層、混入少量舊資料（replay）。哪些層搬/重訓 case by case（語音常重訓靠 input 的層）。無舊資料時才用其他法。

## 關鍵檢查

- 分清「只在乎 target」與「舊能力也要留」。
- 提出保守微調 + replay，並標明 replay 比例（5%）是特定實驗不是通則。
- 對 LoRA 說法保留：少忘是因為少學。
- 誠實：課程對遺忘的證據偏 LLM / 小模型，語音上為推論。

## GOOD 答案必含

1. 只在乎 target -> fine-tune；舊能力也要留 -> multitask / 終身學習；fine-tune 的 loss 看不出舊能力是否遺失，需另設保留任務監測。(EnWz5XuOnIQ S0025-S0033)
2. 微調要保守：source 當初始值、不要跑太多 iteration、lr 調小；conservative training；layer transfer 只訓少數層。(qD6iD4TFsdQ S0009-S0014)
3. 哪幾層搬/重訓 case by case；語音常 copy 後幾層、重訓靠近 input 的層。通則「差異發生在網路哪一端」為推論。(qD6iD4TFsdQ S0014-S0018)
4. 首選 replay：混入少量舊資料（他實驗為 5%，不是通則）；沒有舊資料可讓模型自問自答生成。(Z6b5-77EfGk S0030 S0037-S0042; EnWz5XuOnIQ S0038-S0039)
5. 目標任務學得越好遺忘越多；LoRA 少遺忘是因為少學，雙面刃；dropout、weight decay 擋不住。(Z6b5-77EfGk S0019-S0029; EnWz5XuOnIQ S0031)
6. 證據集中於 1B-7B 語言/語音模型；套到其他模型屬推論。(source-ledger 注記)
7. 一般 ML（標示）：EWC 等具體正則化（課程只有 Y9Jay_vxOsM 提及且缺逐講筆記，不引用）、layer-wise lr、凍結/解凍順序、步數與 lr 具體值。

## 不可

- 說微調後舊能力不應變化或這是資料壞掉。
- 把「replay 5%」當通則。
- 把 EWC 細節當他的講解。
- 說 LoRA 保證不遺忘。
