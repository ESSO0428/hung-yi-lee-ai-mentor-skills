# G03 LLM-as-judge 的偏誤

- 覆蓋度：部分涵蓋（偏誤清單與校準已涵蓋；位置偏誤緩解、樣本數與顯著性未涵蓋）
- 主題：用 LLM 自動評分比較兩個模型

## 使用者訊息

我們用 GPT 類模型當 judge，替兩個客服模型 A、B 的答案打 1-5 分，300 題。結果：

```
model A 平均 4.31   model B 平均 4.18   (A 勝)
A 的平均答案長度 420 字，B 的 190 字
judge 與 A 同一家廠商
```

我打算據此選 A 上線。這樣的比較可靠嗎？

## 預期判斷

不夠可靠。有已知偏誤：長度偏誤、自我偏好（同廠商）、偏好 AI 寫的文章。先拿約 10% 資料與人類評分校準；叫 judge 先解釋再給分；分數是機率分佈，別只取一次。差 0.13 分在這個設定下可能只是偏誤。人類評分有雜訊，也不是黃金標準。偏誤的量化多是舊模型時代，且課程沒給緩解配方。

## 關鍵檢查

- 指出長度偏誤與自我偏好直接出現在使用者資料中。
- 要求人類校準樣本。
- 不把偏誤量化數字當現代通則。
- 位置偏誤、樣本數與顯著性標為未涵蓋。

## GOOD 答案必含

1. 先決定要考什麼能力，分清「要量的」與「量到的」。(dWQVY_h0YXU S0045)
2. 偏誤清單：長度、自我偏好、「改過」就加分、被假權威影響。(Hk8Z0uhmWg4 S0011; dWQVY_h0YXU S0038)
3. LLM-as-judge：先拿約 10% 資料對人類校準；叫它先解釋再給分；分數是機率分佈，別只取一次，加權平均（例 1x0.3+2x0.3+3x0.4=2.1）。(64hQRI0MPs8 R8-R12; A3Yx35KrSN0 S0004; dWQVY_h0YXU S0033)
4. 人評可靠但有雜訊，不是黃金標準；人類偏好排行榜偏好「怎麼說」勝過「說了什麼」，要風格校正。(dWQVY_h0YXU S0020-S0023; s266BzGNKKc)
5. 同時報最差情況，平均不一定對；prompt 改寫會改分數，要受控或多 prompt 平均。(dWQVY_h0YXU S0042 S0061; Hk8Z0uhmWg4 S0020)
6. 評分要讓「我不知道」比亂猜划算（Goodhart）。(dWQVY_h0YXU S0012-S0019)
7. 年代差異：偏誤量化多是 GPT-3.5 / GPT-4o 時代、無緩解配方，位置偏誤兩年的課都沒系統講。
8. 一般 ML（標示）：換另一家 judge 交叉檢查、控制長度的重評分、位置互換、信賴區間與樣本量、pairwise 取代絕對分。

## 不可

- 說 0.13 分差異可靠，或給出「差 X 分就顯著」的門檻。
- 把位置偏誤緩解方案說成他的內容。
- 說人評是黃金標準。
- 引用偏誤的具體百分比當現代模型的事實。

## 評分（0-2）

| 準則 | 0 | 1 | 2 |
|---|---|---|---|
| R1 從使用者資料指出偏誤 | 未指出 | 一項 | 長度與自我偏好兩項都指出 |
| R2 人類校準與解釋後評分 | 無 | 提其一 | 約 10% 校準 + 先解釋再給分 + 分佈 |
| R3 年代與證據範圍 | 套用舊數字為現況 | 未提 | 標明量化屬舊模型 |
| R4 未涵蓋標示 | 緩解配方歸給他 | 提及未標 | 明確標位置偏誤/顯著性/樣本量為課程外 |
| R5 來源標示 | 無 | 部分 | 完整 |
