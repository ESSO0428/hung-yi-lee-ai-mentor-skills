# G01 prompt 還是微調

- 覆蓋度：部分涵蓋（先試 prompt 的立場已涵蓋；決策準則只有 2023 專才/通才一般原則）
- 主題：LLM 輸出品質不穩，想微調

## 使用者訊息

我們用一個閉源 LLM API 做合約條款摘要，輸出常常抓錯重點、格式也不一致。目前 prompt 只有一句「請摘要以下合約條款」。我們有 300 筆人工寫的好摘要，老闆想花兩週微調一個開源 7B。這是對的方向嗎？

## 預期判斷

先別微調。先查 prompt 是不是前提沒給（讀者、用途、長度、格式、重點定義），說不清的需求給貼近領域的範例（4-8 個後邊際效益小），需要的知識直接給資料。閉源 API 本來就只能改 x，沒有參數可改。微調是後手；專才在單一明確任務有機會贏，但 300 筆和 7B 的實際勝負課程沒給判據，也要警告微調的風險。

## 關鍵檢查

- 區分改 f（微調）與改 x（輸入），閉源 API 只能改 x。
- 逐項補前提，而不是找「神奇咒語」。
- 指出微調的風險與評估要求。
- 對微調 vs prompt 的決策準則標「課程只有一般原則」。

## GOOD 答案必含

1. 總開關：這堂課沒有任何模型被訓練；先窮盡 x（任務、前提、範例、資料、拆解、工具），再談微調。(lVdajtNpaGI S0002; M2Yg1kwPpts S0009)
2. 查前提：答非所問常是前提沒給；補場景、格式、字數。(lVdajtNpaGI S0010; A3Yx35KrSN0 S0013)
3. 說不清的需求給範例，範例貼近領域，4-8 個後邊際效益小；大模型會被錯範例帶偏。(lVdajtNpaGI S0013; aZ_jXZvxyVg)
4. 要直說「做什麼」，不說「不要做什麼」。(A3Yx35KrSN0 S0006; M2Yg1kwPpts S0028)
5. 不要找咒語，數據：GPT-3.5 數學題無咒語 72%->有 88%（2023），2024 差距縮小到 85%->89%；當假說實測。(lVdajtNpaGI S0008; A3Yx35KrSN0 S0005)
6. 專才 vs 通才：單一明確任務、只在乎最佳表現，專才有機會贏；證據只是翻譯一例、樣本小。(F58vJcGgjt0 S0005-S0009)
7. 後訓練「不到沒有辦法才用」，像給 AI 大腦動手術，有風險（遺忘）。(EnWz5XuOnIQ，見 shift 主題 F；微調前後都要回測舊能力：Z6b5-77EfGk S0051)
8. 一般 ML（標示）：實際的決策準則、300 筆是否足夠、7B 與閉源模型的比較；課程沒有決策樹。

## 不可

- 直接說「微調比較好」或「prompt 一定夠」。
- 給出具體資料量門檻當他的說法。
- 說他教了「prompt vs 微調決策樹」。
- 推薦咒語。

## 評分（0-2）

| 準則 | 0 | 1 | 2 |
|---|---|---|---|
| R1 f/x 區分與先改 x | 直接微調 | 提 prompt 無理由 | 明說閉源只能改 x，並給逐項補前提的做法 |
| R2 前提與範例的具體建議 | 無 | 泛泛 | 具體（讀者、格式、範例 4-8 個貼近領域） |
| R3 微調風險 | 無 | 提風險 | 提遺忘/回測舊能力與專才證據的限制 |
| R4 未涵蓋標示 | 虛構決策準則 | 未標 | 明說課程沒有決策樹，標一般 ML |
| R5 來源標示 | 無 | 部分 | 完整 |
